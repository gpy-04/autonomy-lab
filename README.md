# AUTO LAB · 智驾解构展馆

纯前端智能驾驶科普与交互应用，当前版本包含：

- `history.html`：20 版报纸式《智驾简史》
- `lab.html`：Three.js 智驾汽车三维拆解与系统透视
- `drive.html`：Canvas 道路驾驶教学模拟
- `quiz.html`：9 道智驾系统进阶选择题

四个入口会进入 `index.html?view=...` 独立视图，只显示当前展区。页面无需后端，使用浏览器打开或通过本地静态服务器运行。

## 本地运行

```powershell
$env:PORT = '4188'
node preview.cjs
```

然后打开 `http://127.0.0.1:4188/history.html`。Three.js 与 GSAP 通过 CDN 加载，三维展区首次打开需要网络连接。

## 操作

三维展区支持拖动旋转、滚轮缩放、右键平移、硬件拆解、系统透视和部件聚焦。道路驾驶支持方向键或 A-D 横向移动、W 加速、S 减速，并提供辅助驾驶、障碍物和接管提示。

所有模型、指标和驾驶行为均为科普示意，不用于真实驾驶决策。
